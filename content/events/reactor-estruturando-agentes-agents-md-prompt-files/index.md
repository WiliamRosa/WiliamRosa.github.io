**📅 13 de outubro de 2026 · ⏰ 19h30 (BRT) · 💻 Evento online**

Segunda sessão da série sobre agentic development do Microsoft Reactor São Paulo, dessa vez aprofundando como estruturar o comportamento de agentes de código usando AGENTS.md e prompt files reutilizáveis.

O foco é organização prática: como separar instruções por tarefa, definir responsabilidades claras entre diferentes agentes, e evoluir um setup inicial simples para um modelo modular e reutilizável no dia a dia de desenvolvimento.

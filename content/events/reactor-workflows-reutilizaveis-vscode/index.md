**📅 20 de outubro de 2026 · ⏰ 19h30 (BRT) · 💻 Evento online**

Terceira sessão da série do Microsoft Reactor São Paulo sobre desenvolvimento com agentes de código, voltada pra construção de workflows reutilizáveis no Visual Studio Code.

A ideia é sair do prompt avulso e organizar bibliotecas de prompts e fluxos de trabalho pra cenários recorrentes, como desenvolvimento de features, refatoração e documentação, buscando mais previsibilidade e eficiência no uso do GitHub Copilot.
